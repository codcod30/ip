\# AI Usage Log



\## Tools Used

\- ChatGPT

\## How AI Was Used



\- Assisted with debugging.

\- Clarified Git concepts (e.g., difference between `git push` and `git push origin master`).

\- Suggested small refactorings to improve readability and structure.

\- Generated ideas for additional test cases and JavaDoc improvements.



\## Interesting Observations



\*\*What worked well:\*\*

\- Explaining error messages clearly.

\- Suggesting cleaner alternative implementations.

\- Saving time when brainstorming improvements.



\*\*What didn’t work as well:\*\*

\- Some suggestions required adjustments to match project coding style.

\- AI-generated examples occasionally needed modification to fit the existing code structure.

\- ChatGPT does not understand what it was required to do.



\*\*Overall impact:\*\*

\- AI significantly reduced debugging time and helped improve code quality.

\- Estimated time saved: approximately several hours across multiple increments.

\- AI was most useful as a productivity and learning aid, while final decisions and testing were done manually.
